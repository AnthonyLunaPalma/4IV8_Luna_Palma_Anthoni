Todos los formularios que estan en internet tienen metodos de programacion por defecto. Estos metodos nos sirven para posdder hacer las acciones principales comoson: Acciones para poderse conectar con los servidores, a traves de las arquitecturas cliente-servidor. Todos los formularios utilizan el metodo GET, y el segundo metodo principal es el POST, aunque existen otros metodos que se encargan del intercamnbio de informacion. GET: Este metodo envia por medio de la URL toda la informacion del formulario a traves del navegador. Su funcion principal es obtener los datos del servicio; pero es el metodo mas vulnerable de todo; derivado a que se pueden generar inyecciones de codigo. POST: Este metodo se encarga de registrar una nueva entrada al sistema, tambien utiliza la URL como envio por defecto; pero su facultad es poder ocultarla, eston significa que los datos no son visibles para el usuario comun en el navegador expresiones regulares en JS (documentacion firefox).
